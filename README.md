## CareLink

CareLink is a voice-based resource navigation service developed for the 2024 Esri Intern Hackathon. Users describe their location and needs by phone, and the system uses Twilio, spaCy NLP, and ArcGIS services to identify the request, locate nearby support resources, and provide contact information.

The project includes an Express.js phone service for call handling and speech collection, plus a Flask processing service for natural-language classification, geocoding, shelter matching, and call logging.
